# TUPE Barbershop Appointment System

A web-based barbershop appointment booking system developed to streamline scheduling, manage appointments, and improve customer experience for barbershops.

This project was built as an academic project to apply full-stack web development concepts, including frontend UI development, backend logic, and database management.

---

## 🚀 Features

- User registration and authentication
- Appointment booking and scheduling
- View and manage booked appointments
- Admin/staff management of appointments
- Responsive and user-friendly interface
- CRUD operations for users and appointments
